# Historical documentation

`legacy-cmake-toolkit.md` documents the removed, project-specific CMake facade.
It is retained for reference only; do not use its `dagflow_add_*` recipes.
The supported library toolkit has the `boilerplate_*` namespace and lives in
`cmake/boilerplate/`. See [the build/layout guide](../build-and-layout.md).

Benchmark reports retain original source paths and experiments to preserve
provenance. Their previous Python orchestration is not part of the new build.
